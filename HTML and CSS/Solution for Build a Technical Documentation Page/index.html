Grid Basics

CSS Grid is a two-dimensional layout system for arranging content in rows and columns.

A grid container is created by setting the display property to grid on a parent element.

display: grid;
  • Use grid for page regions and card layouts.
  • Use clear spacing so content is easy to scan.
Creating Columns

Columns are defined with grid-template-columns, which accepts fixed, flexible, and repeated values.

The fr unit distributes remaining space across tracks in a predictable way.

grid-template-columns: 1fr 2fr;
Placing Items

Grid items can be placed automatically or assigned to named grid lines.

Line-based placement makes complex interfaces easier to maintain.

grid-column: 1 / 3;
  • Let auto-placement handle simple flows.
  • Use line numbers when an item must span tracks.
Responsive Layouts

Responsive grids can adapt without many breakpoints by using minmax and repeat.

Media queries are still useful when the whole layout needs to change at a specific width.

grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
Grid Accessibility

Grid changes visual layout, but it should not create a confusing reading order.

Keep related content together in the source so keyboard and screen reader users have a logical path.

gap: 1rem;
  • Preserve meaningful document structure.
